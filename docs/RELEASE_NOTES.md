# ClearGuard 0.0.1

首个正式版本。ClearGuard 通过完整内容核验查找重复文件，支持扫描单个文件夹和已挂载的本地磁盘。

- 可以单独勾选文件，也可以全选当前筛选结果中的副本。每组至少保留一份。
- 清单显示保留和将要移入回收站的文件。检测到占用、附加数据或文件变化时会保护相关副本。
- 清理前二次检查，确认后移入系统回收站，并保存本机清理记录。
- 大文件校验按块比较，已有差异的候选可以提前退出。项目提供可复现的性能测试。

下载 macOS 磁盘映像或 Windows x64 安装包，无需单独安装 Python。Mac 请选择与你芯片相符的版本。Windows 安装仅面向当前用户，同时提供免安装 ZIP。初版未做 Apple Developer ID 公证或 Windows Authenticode 签名。

源码、测试和安装打包脚本均采用 MIT 许可证。第三方组件保留各自许可。
